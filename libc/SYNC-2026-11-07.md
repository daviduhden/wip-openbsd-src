## Corrected defects

### Supplementary-group failure

NEW tested `setgroups(...) == 1`, although failure returns -1. The local delta
uses `== -1`, preserving cleanup and failure propagation. The new login_cap
regression establishes that earlier group setup is permitted and that an
actual setgroups call fails with EPERM, then requires setusercontext to
propagate failure. It skips privileged or mismatched credential contexts.
This regression has not been compiled or run. The manual now documents the
new wscons flag and actual group setup interfaces.

### GCC pointer fetch

The former GCC path could evaluate object, operand and order again during a
CAS retry. The wrapper now captures each once before starting the operation. The
former retry loop also used ordinary C pointer arithmetic, which could
introduce undefined behavior outside the original array. Captured operands
are now scaled as unsigned pointer-width displacements and passed directly
to GCC's raw atomic fetch builtin, without a C pointer increment or CAS loop.
This follows [GCC's documented pointer builtin semantics](https://gcc.gnu.org/onlinedocs/gcc/_005f_005fatomic-Builtins.html).
The type choice also keeps integer-fetch macro branches syntactically valid.
Unary promotion when capturing the operand accepts bit-field operands;
regressions cover both integer and pointer bit-field add/sub operations.
Host and native regressions cover side-effect counts and GCC positive/negative
out-of-array address roundtrips without dereferencing them. These are source
additions, not executed evidence.

### Native Threads provider

pthread_create/join/detach and the mutex attribute operations needed by the
wrappers are supplied by lib/librthread, whose Makefile sets LIB=pthread.
The previous local integration put all wrappers in libc and introduced the
wrong dependency direction. All 25 C11 Threads functions now belong to
libpthread. Six newly internal pthread dependencies have PROTO_NORMAL and
matching DEF_STD aliases, preserving their existing public names. The host
harness references the relocated source; native Threads regress links
-lpthread and the manual documents -pthread.

Historical upstream ABI types, symbol names and library major versions are
unchanged. **The provider of the 25 local C11 symbols changes:** consumers of
the earlier local extension must relink with -pthread. Local libc remains
104.1 for atomic/bit exports; local libpthread becomes 28.2 from upstream
28.1. This is a necessary correction of the local ABI extension, not a claim
of binary compatibility with previously built local Threads consumers.

### Header matrix provenance

Independent header cases in every language mode, joint orders and C++ cases
now verify this tree's include guards. Predictable shared /tmp diagnostic
files were replaced with private mktemp directories. Every former test case
is retained or strengthened. Resource-header shadowing remains a compiler
property; the guard checks must fail instead of silently testing GCC's copy.
